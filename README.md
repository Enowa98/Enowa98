# Enowa98

## Russian Lane (`russian-lane/index.html`)

A single-page app for learning Russian for Dota 2 chat and for singing along to songs:

- **Alphabet**: all 33 letters grouped by difficulty, a sound quiz, and a map of the Russian keyboard layout.
- **Dota chat**: about 120 real chat phrases and slang terms, plus a chat decoder that uses Claude.
- **Songs**: titles from my playlist to practice reading, and a lyrics breakdown with pronunciation, translation and words you can save.
- **Review**: spaced-repetition flashcards, with a reading mode and a typing mode.

## Live Subs (`live-subs/`)

A Windows program that shows live Russian subtitles and a translation for any audio the PC plays, such as Twitch streams or Dota 2 voice chat. It uses Whisper on the GPU. Setup steps are in `live-subs/README.md`.
